Data & privacy

Healio standalone stores records on this device using browser storage. It does not upload health data to a server.

Stored data

Activities, water entries, sleep sessions, measurements, workouts, meals, mood check-ins, goals, habits, reminders, journal entries, profile details, and preferences.

Delete data

Deleting data is permanent for this browser unless you have a backup. Export first if you want to keep a copy.

Privacy notes

  • Browser storage is not encrypted by this app; protect your device account.
  • Notifications are shown by your browser and may appear on your device screen.
  • This app has not undergone a regulatory or security compliance assessment.

Help & about

Healio — Your Health, Simplified.

A local-first personal wellness tracker for learning and demonstration.

How to use

  1. Choose a section from the sidebar or mobile navigation.
  2. Enter your own records; the dashboard updates from saved entries.
  3. Use Reports to export CSV data or print a PDF.
  4. Use Data & Privacy to back up or delete your records.

Healio 4.0 integration status

Works in this standalone build

Local wellness tracking, habits, skincare journal, reminders while the page is open, charts, CSV/JSON export, print-to-PDF, themes and wearable CSV/JSON import.

Requires external configuration

Verified Google sign-in, secure multi-user accounts/cloud sync, live AI responses, browser push notifications while closed, and direct Health Connect/Apple HealthKit sync.

For privacy, do not treat local browser sign-in as secure authentication. The backend starter demonstrates server-side Google ID-token verification and a protected AI endpoint; configure and deploy it before using real accounts or health data.

Known limitations

  • No automatic sensor, wearable, or health-platform integrations.
  • No cloud sync or server-side authentication is active in this standalone HTML build; see the backend starter and setup guide in the project ZIP.
  • Reminders can only be checked while the page is open; closed-browser push is not configured.
  • PDF export uses the browser's print-to-PDF feature.
